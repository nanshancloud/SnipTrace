## 4. 已知偏差

| 设计条目 | 现状 | 原因 |
|---|---|---|
| §4.3「空隙使用斜纹提示」 | 用 HUD 文字「包含未覆盖区域，导出时以黑色填充」替代 | 空隙不属于任何显示器，需额外全屏装饰窗口 |
| §3.2「选完区域再选帧率」 | 帧率与上限在 GIF/录屏页配置 | 交互取舍，避免选区流程二次弹窗 |
| §6.6 跨屏录制 | 仅支持单显示器 | 设计稿列为 P1 |
| §7.6 抖动质量档 | 单开关（高质量抖动） | 满足 P0，无多档量化策略 |

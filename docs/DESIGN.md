## 1. 产品定位

**产品名：屏迹 SnipTrace**

**主张：截得准，讲得清。**

参考 Snipaste 的快捷、精准、可标注体验，但不复制其品牌与视觉。产品面向开发、产品、设计、教学、技术支持等需要快速截图、解释问题、制作操作步骤的人群。

核心差异点：

- 截图、标注、GIF、录屏在同一套工作流内完成。
- 序号标签专为“步骤说明”设计，支持自动编号、拖动和重排。
- 完全本地处理，无账号、无云端、无遥测。
- 适配 16:9、16:10、3:2、21:9、32:9、竖屏及任意选区的截图与录制。
- 轻量、快速、键盘优先。

产品原则：

1. **快**：快捷键到选区覆盖层不超过 150 ms。
2. **准**：截图和导出严格按物理像素，不产生 DPI 模糊或偏移。
3. **清楚**：序号标签、箭头和文本帮助用户一次讲清步骤。
4. **可控**：录制可见、可暂停、可取消，失败不留半成品。
5. **自适应**：界面随分辨率和 DPI 变化，图片和视频永远不拉伸。

## 2. 产品范围

### 2.1 P0：首版范围

#### 截图

- 全局快捷键唤起区域截图。
- 冻结桌面后选择区域，避免画面变化。
- 实时显示选区尺寸、坐标和宽高比。
- 支持 16:9、16:10、4:3、3:2、1:1、9:16、原始比例和自由比例。
- `Enter` 确认、`Esc` 取消、方向键微调选区。
- 跨显示器连续选区，可从一个显示器拖到另一个显示器。
- 当前显示器全屏截图。
- 所有显示器全屏截图。
- 可选是否包含鼠标指针。
- 截图后复制、保存、进入编辑器或钉图。

#### 标注编辑器

- 矩形、椭圆、箭头、画笔、高亮笔、文本、序号标签。
- 颜色、线宽、字号、透明度。
- 选择、移动、缩放已有标注。
- 撤销、重做，至少 50 步。
- 缩放画布：适应窗口、25%–400%。
- 复制到剪贴板、保存 PNG、钉图置顶。
- 完整键盘操作。

#### GIF 录制

- 选区录制，输出循环 GIF。
- 帧率：5、10、12、20、25 FPS。
- 3 秒倒计时。
- 暂停、继续、停止、取消。
- 显示录制时长、帧数和预计体积。
- 最大时长和最大帧数保护。
- 完成预览、保存、打开所在文件夹。

#### 屏幕录制

- 单显示器内选区或当前显示器全屏录制。
- 仅画面录制，输出 H.264 MP4。
- 默认 30 FPS，支持 24、30、60 FPS。
- 暂停、继续、停止、取消。
- 录制边框与悬浮控制条。
- 奇数宽高自动裁为偶数，不拉伸画面。
- 失败时清理临时文件，不产生不可播放的半成品。

#### 桌面集成

- 系统托盘常驻：图标随任务栏明暗自适应（读 `SystemUsesLightTheme`，并监听偏好变化），
  也可固定为彩色 / 浅色；录制中切换为琥珀色。
- 全局快捷键。
- 最近截图和最近录制。
- 设置：输出目录、帧率、快捷键、是否复制、是否包含光标。
- 开机启动开关。
- 单实例运行。
- 窗口尺寸、位置和最大状态持久化。

### 2.2 P1：后续增强

- 跨显示器录制。
- 延时截图。

## 3. 核心用户流程

### 3.1 截图流程

1. 用户按 `F1`，主窗口自动隐藏。
2. 立即捕获桌面冻结帧。
3. 在鼠标所在显示器弹出选区覆盖层，并为所有显示器建立协同覆盖层。
4. 用户可在任意显示器开始拖动，选区可连续跨越显示器边界。
5. 拖动框选时放大镜跟随光标，同时显示尺寸、坐标、比例与像素颜色。
5. 松开鼠标后显示浮动工具条：标注、序号、复制、保存、钉图、GIF、录屏、取消。
6. 点击“标注”或按 `Enter` 进入编辑器。
7. 完成标注后复制、保存或钉图；保存时另存为对话框期间截图画面与标注保持显示（覆盖层临时取消置顶），
   保存成功或取消保存后才退出截图状态。

目标时延：

- 单屏 1080p 快捷键到覆盖层：小于 150 ms。
- 双屏 1080p 快捷键到覆盖层：小于 250 ms。
- 三屏 4K 快捷键到覆盖层：小于 600 ms。
- 选区确认到编辑器打开：小于 200 ms。
- 1080p 截图内存峰值：小于 120 MB。
- 三屏 4K 跨屏截图内存峰值：小于 600 MB。

### 3.2 GIF 录制流程

1. 用户按 `Ctrl+Shift+G`。
2. 选择录制区域和比例。
3. 弹出录制前控制条（参考 QQ 录屏）：确认格式（MP4 / GIF）与清晰度，点「开始录制」或「退出录制」。
4. 3 秒倒计时后开始录制。
5. 录制边框位于画面外侧，控制条显示时长、帧数、暂停、停止、取消。
6. 停止后完成 GIF 封装并打开「制作GIF」预览窗口。
7. 预览窗口可播放、拖拽进度、切换循环，并支持另存为、复制或打开文件夹。

### 3.3 屏幕录制流程

与 GIF 流程一致（同样经过录制前控制条），但使用独立编码管线：

- 默认 30 FPS。
- 默认输出 MP4；清晰度档位（标准 / 高清 / 超清）映射为码率，标准档按分辨率自动估算。
- 不设 120 秒硬限制，但提供磁盘空间预警。
- 暂停时间不计入成片，不产生冻结画面。
- 显示器分辨率或排列发生变化时自动停止并封装。

### 3.4 序号标签流程

1. 选择“序号”工具或按 `N`。
2. 在画布点击，依次生成 1、2、3……
3. 工具保持激活，可连续放置。
4. 拖动标签调整位置。
5. `Delete` 删除选中标签。
6. 支持“重排编号”和“重置编号”。

## 4. 界面设计

### 4.1 主窗口

建议尺寸 1100 × 720 DIP，可缩放，最小 860 × 560 DIP。

| 区域 | 内容 |
|---|---|
| 自定义标题栏 | 品牌、状态、最小化、关闭 |
| 左侧导航栏 | 截图、GIF、录屏、最近、设置、关于 |
| 主内容区 | 标题、三种模式入口、最近捕获 |
| 底部状态栏 | 快捷键提示、输出目录、托盘状态 |

主内容区：

- 标题：“捕捉，标注，讲清楚”
- 副标题：“区域截图、GIF 动图与高清录屏，一次完成”
- 三张并排模式卡：
  - 区域截图：`F1`
  - GIF 录制：`Ctrl+Shift+G`
  - 屏幕录制：`Ctrl+Shift+R`
- 每张卡片包含用途说明、快捷键和主按钮。
- 下方为最近捕获横向缩略图。
- 空状态使用轻量操作引导，不使用空白占位。

### 4.2 响应式布局

以窗口内容区宽度（DIP）为断点，不以物理分辨率为断点。

| 内容区宽度 | 布局 |
|---|---|
| ≥ 1280 DIP | 展开：左侧导航 + 三列模式卡 + 最近记录侧栏 |
| 1040–1279 DIP | 标准：左侧导航 + 三列模式卡 + 最近记录下移 |
| 860–1039 DIP | 紧凑：窄导航栏，模式卡改为纵向列表 |
| < 860 DIP | 极简：顶部标签导航，单列内容，全部可滚动 |

高度自适应：

| 内容区高度 | 行为 |
|---|---|
| ≥ 760 DIP | 显示完整标题、引导插画和最近记录 |
| 600–759 DIP | 隐藏装饰插画，压缩标题区 |
| < 600 DIP | 隐藏副标题，最近记录折叠，内容可滚动 |

具体规则：

- 初始窗口尺寸按工作区的 84% 宽、82% 高计算，并限制在合理范围内。
- 最大化时主内容最大宽度约 1360 DIP 并居中。
- 超宽屏不把卡片拉伸到整屏宽。
- 16:10 屏幕多出的纵向空间用于显示更多最近记录。
- 16:9 屏幕优先压缩装饰区域，保证三个模式入口首屏可见。
- 主要按钮最小点击区域 40 × 40 DIP。
- 窗口尺寸和位置持久化；恢复时若超出工作区，自动校正。
- 显示器排列或分辨率变化后重新计算窗口位置。

### 4.3 选区覆盖层

- 以全屏冻结帧为背景，所有显示器共享同一张虚拟桌面截图。
- 每台显示器一个覆盖窗口，由同一个选区控制器协同。
- 选区使用虚拟桌面物理坐标，可跨越任意相邻显示器。
- 选区外使用 55% 黑色遮罩。
- 选区内保持原图亮度。
- 1 px 强调色边框和四角控制点，跨屏时在接缝处保持连续。
- 放大镜作为独立窗口：**仅在按住鼠标拖动框选范围时出现**，局部像素放大、中心像素高亮取色，
  并显示宽 × 高、比例、选区原点与光标坐标；松开鼠标或进入标注模式即隐藏。
- 工具条优先位于选区下方，空间不足时自动翻转或切换到内部。
- 工具条放置在选区活动角所在的显示器，并钳制在该显示器工作区内。
- 跨屏选区下，工具条跟随最后一次鼠标所在的显示器。
- 工具条参考 Snipaste：单行图标条，贴选区右下角、右缘对齐选区右缘，
  默认顺序为「比例▾ ｜ 图形 箭头 画笔 文字 序号 马赛克 颜色 ｜ 保存 钉图 ｜ GIF 录屏 ｜ 回退 前进 ｜ 取消 精标 ｜ 复制」
  （「复制」默认贴最右侧，取完即用）；
  无选区时不显示。
  按钮的显隐与顺序由设置 `SelectionToolbar`（`List<ToolbarItemSetting>`）决定，
  构建时按列表逐项生成，跨分组（比例 / 工具 / 动作 / 录制 / 历史 / 决策）自动插分隔线；
  列表经 `SelectionToolbarItems.Normalize` 清洗（丢未知与重复、补齐缺失项），手改配置不会把工具条弄坏。
- 「回退 / 前进」撤销或恢复覆盖层上的一步标注（等价 `Ctrl+Z` / `Ctrl+Y`、`Ctrl+Shift+Z`），
  可用状态跟着 `AnnotationDocument.CanUndo` / `CanRedo` 走，没有历史时按钮置灰。
- 工具条按钮的增删与排序在设置页「选区工具条」区块完成：区块里直接画出**与真机同款的单行图标工具条**
  （同一套图标几何见 `SelectionToolbarIcons`，隐藏项变暗、跨分组插分隔线），
  **按住任意按钮拖动即可换位**，点按钮切换显示 / 隐藏，一键恢复默认；改动即时写回设置，下一次截图生效。
- 工具条外观对齐 Snipaste：圆角 9、1 px 边框、中性悬停高亮（不用强调色铺底），
  底色走 `ChromeBrush`（深色 `#F2161E28`、浅色 `#F7FFFFFF`），避免出现死黑块。
- 比例芯片收在「比例▾」弹出层里，选中后自动收起；按钮上始终显示当前比例。
- 接近屏幕边缘时放大镜自动翻转；光标落到工具条上、或未处于拖动状态时放大镜隐藏。
- 图标按钮与比例芯片悬停时显示悬浮介绍（功能说明 + 快捷键），
  用独立置顶的不激活窗口实现，避免被全屏置顶的覆盖层遮挡。
- 右键：选区界面不再弹菜单，右键即取消本次截图（拖动过程中右键只中断该次拖拽、保留已选区）；
  右键菜单只保留在钉图窗口里。
- 覆盖层标注（Snipaste 式直标）：工具条提供 图形 / 箭头 / 画笔 / 文字 / 序号 / 马赛克 切换钮与颜色样本，
  以及回退 / 前进两步历史按钮；选中工具即进入标注模式（再点一次或 `Esc` 回到框选模式），拖动仅在选区内绘制；
  文字工具在点击处弹出输入框，`Enter` 提交。覆盖层不再提供「选择」「橡皮」按钮：
  改标注靠回退 / 前进与「精标」进编辑器处理。
- 「图形」「箭头」是带子选项的合并按钮：图形 = 矩形 / 椭圆 / 直线，箭头 = 箭头 / 直线；
  点击激活工具并在上方弹出芯片层切换子选项，按钮右下角小三角提示可切换。
  子选项记在 `ToolbarItemSetting.Variant`（`SelectionToolbarItems.NormalizeVariant` 收敛到合法值），
  切换后立即写回设置，下次截图沿用。直线用 `AnnotationKind.Arrow` + `ArrowHead.None` 表示。
- 旧配置迁移：`rectangle` / `ellipse` 并入 `shape` 并记住子选项，`select` / `eraser` 直接丢弃
  （`SelectionToolbarItems.Normalize`），手改过的旧工具条不会残留无效按钮。
- 「马赛克」是**笔刷**：按住拖动沿轨迹打码（笔迹按折线采样，`IsPolyline` 含 Mosaic），
  扫过的块按**标注坐标**网格对齐（只选中心距笔迹 ≤ 半块的 cell，绘制足迹 ≤ 1 块），逐块取**源图**平均色填充
  （`AnnotationRenderer.DrawMosaic`）。`imageOrigin` 只用于把取样矩形换算到源图像素——
  覆盖层跨显示器切片与编辑器 / 导出共用同一相位，看到的与导出的完全一致。
  块大小 = `clamp(线宽 × 2, 8, 48)`，滚轮改线宽即改块大小（到边界返回「未变化」，不再重绘）。
  平均色按 (源图, 块, 网格位置, 图像原点) 缓存、画刷按颜色复用，拖动时只算新增块。
  命中按笔迹到线段的距离 + **1 块**半径（`Bounds` 同额外扩），与可见足迹一致；
  水平 / 单点笔迹也能缩放，橡皮可擦除马赛克。颜色 / 透明度对马赛克无效，选中时禁用这两个面板。
- 选区改大小：四角 10 px 命中范围内按住拖动即可改大小（普通模式下，
  标注工具绘制中不抢角点），对角固定、越界裁剪到虚拟桌面、小于 8 px 的中间态不落地
  （`RectResize.HitCorner` / `FromCorner`，纯几何、可单测）；角上光标变斜向双箭头。
  已画标注**不再因为改选区而作废**：左上角位移时标注反向平移以保持贴住原屏幕位置，
  画布尺寸经 `AnnotationDocument.ResizeCanvas` 跟随（导出按新尺寸渲染，越界部分自然裁掉）。
  方向键微调选区与切换比例时同样按这套对齐。
- 序号标记（工具条「①」）：进入后点击选区即放置自动递增编号（`AnnotationDocument.NextNumber`）；
  弹出层提供 圆 / 三角 / 方 / 五边 / 六边 / 心形 / 圆角 七种外形与 填充 / 边框 两种模式，
  形状顶点由 `BadgeShapes.Outline` 统一生成，工具条图标、画布与导出共用同一套几何。
- 滚轮：矩形 / 椭圆 / 箭头作用于**最近画的**那一个标注，每格 ±1 px **线宽**
  （1–16，箭头端头按线宽同步缩放，长度 `clamp(4.2 × 线宽, 8, 44)`）；文字 / 序号改字号。
  **画笔 / 马赛克是笔刷**：滚轮只改「下一笔」的笔刷大小（画笔线宽 1–16；马赛克线宽 4–24 → 块 8–48 px），
  **已经输出的笔迹完全不变**（`AdjustOnWheel` 对笔刷类直接返回 false，笔刷大小存在覆盖层工具状态里）。
  三处入口都接通同一份边界 `AnnotationEditing.AdjustBrushWidth`：覆盖层选区内滚轮（不再要求光标在选区内）、
  选区工具条画笔 / 马赛克按钮上的滚轮（独立顶层窗口直接转发，窗口级兜底覆盖按钮间隙）、编辑器画笔 / 高亮 / 马赛克工具下的滚轮（此工具下不再缩放画布，
  其余工具滚轮仍缩放）；调整后覆盖层在工具条浮层、编辑器在状态栏 + 面板高亮显示当前笔头尺寸。
  编辑器里马赛克笔头线宽独立存储（与画笔 / 高亮的 `_style.StrokeWidth` 分开），进编辑器时从带入的最后一笔马赛克继承；
  画布样式按当前工具切换，两笔头互不串扰。到边界后不再重复触发反馈。
- 工具条右端的「复制」与「精标」是两件事：复制（`Ctrl+C`）直接把标注烘焙进图片放进剪贴板，
  不进入编辑器；精标（`Enter`，强调色 + 铅笔图标）进入标注编辑器继续调整。
  两者都用图标 + 文字标签，避免只看图标分不清。
- 两种标注途径：覆盖层直标（工具条工具）与编辑器精标（「精标」按钮进入）；
  覆盖层标注随选区结果带进复制 / 保存（烘焙进图片）、钉图（保留标注文档，可继续悬浮选中 / 拖动 / 调整）与编辑器（作为初始文档继续编辑）；
  重新框选会使覆盖层标注作废。
- 窗口吸附（参考 Snipaste）：无选区时探测光标下的顶层窗口，
  虚线高亮窗口范围并在放大镜中显示其尺寸；单击整选该窗口，
  按下后拖动超过 5 px 才转为自由框选。
- 窗口探测按 Z 序枚举，排除本进程窗口、桌面 / 任务栏外壳窗口与被遮蔽的 UWP 窗口，
  使用 DWM 扩展边框（不含不可见阴影）。
- 超宽屏上工具条跟随选区，不固定贴边。
- 选区覆盖到显示器之间的未覆盖空隙时，使用斜纹提示，导出时填充黑色。

选区交互：

| 操作 | 行为 |
|---|---|
| 拖动 | 从任意显示器创建选区 |
| 跨屏拖动 | 选区连续扩展到其他显示器 |
| 拖动控制点 | 调整选区 |
| 方向键 | 移动选区 1 px |
| `Shift` + 方向键 | 移动 10 px |
| 按住 `Shift` | 临时锁定当前宽高比 |
| `Enter` | 确认 |
| 双击 | 确认并复制 |
| `Esc` | 关闭所有覆盖层并取消 |
| 拖动中右键 | 中断本次拖拽，回到无选区状态 |
| 无选区右键 | 退出截图 |
| 有选区右键 | 退出截图（选区界面不再弹菜单；菜单只在钉图窗口） |

### 4.4 标注编辑器

布局：

- 顶部：文件名、撤销、重做、清除全部、复制、保存、钉图、关闭。
- 左侧：选择、矩形、椭圆、箭头、画笔、高亮、马赛克（`M`）、文本、序号、橡皮（`X`）。
  工具按钮是带底色与细边框的块状按钮（不是裸文字），选中态用强调色底 + 强调色边框 + 左侧 3 px 指示条，
  悬停提亮，禁用降透明度；窄屏下按钮尺寸不变，保证点击目标。
- 右侧：颜色、线宽、箭头模式（单向 / 双向 / 无头 / 直角）、字号、透明度、
  序号形状（圆 / 三角形 / 四边形 / 五边形 / 六边形 / 正心形 ♥ / 圆角）、
  填充方式（填充 / 边框）、改样式后重新计数、序号重排与重置。
- 中央：棋盘格画布，显示原图与标注。
- 底部：图片尺寸、缩放比例、当前工具。

交互：

- **选择**：点选标注后拖动移动，拖四角手柄缩放（文本与序号改字号）；
  双击文本进入内容修改，`Enter` 提交。单条箭头选中后显示端点手柄，
  拖端点重新定向、拖中间顶点改折线。
  虚线选框与 8 个调整手柄**只在「选择」工具下出现**（`AnnotationCanvas.ShowsSelectionBox`）：
  画笔、箭头、橡皮等绘制过程中不画调整框，避免误以为框可以拖动；绘制工具的鼠标指针一律是十字。
- **选中即浮出样式条**：单选文本 / 序号时在选区上方浮出「小 / 中 / 大」字号 + 颜色块；
  单选图形时换成「细 / 中 / 粗」线宽（马赛克为「小 / 中 / 大」块大小）+ 颜色块。
  档位取自与右侧面板相同的 `FontSizes` / `StrokeWidths` / `MosaicWidths` 常量，用「最近档位」判高亮，
  不会出现一边亮一边全灭；拖动 / 缩放标注、滚轮缩放时跟随选区（`AnnotationCanvas.ContentMoved` / `ZoomChanged`），
  上方空间不足自动移到下方、夹在画布内并避让窄屏属性面板浮层；进入文本编辑或切到绘制工具即收起。
  样式条只做快捷应用，完整选项仍在右侧面板。
- **右侧面板联动左侧工具**：点「箭头模式」自动切到箭头工具；
  点「序号形状」或「填充方式」自动切到序号工具，并把该形状 / 填充记为新建号标的默认值
  （没有选中号标时也会记住，下一次放置直接生效）。
- **箭头**：按住拖动得到两点箭头；单击起点后连续单击追加折线，光标实时预览下一段，
  `Enter` / 右键 / 双击结束，`Esc` 取消。模式见右侧「箭头模式」，已选中的箭头切换模式立即生效；
  直角模式下每段按横 / 竖吸附。
- **橡皮**：按住拖动擦除画笔、高亮与马赛克笔迹（文本、箭头、序号、图形不参与），
  一次拖动合并为一步撤销。
- **高亮半透明**：高亮按荧光笔处理，渲染时在样式不透明度之上再压一档
  （`AnnotationEditing.HighlightOpacity = 0.38`，`RenderOpacity()` 统一计算），
  底下的文字与线条始终看得见；右侧「透明度」仍然叠加生效（50% → 0.19）。
  覆盖层、编辑器与导出共用同一个渲染入口，所见即所得。
- **撤销 / 重做**：历史以「编辑会话」为单位——`BeginEdit` 拍快照、`EndEdit` 提交，
  只有**确实发生了变化**（`MarkChanged` / 增删 / 改画布）才入栈并清空重做栈；
  选中、点空白、切工具、重复点同一个样式等空操作**不再清空重做栈**（这正是
  「撤销后重做按钮像坏了」的根源）。`BeginEdit` 支持嵌套（`_editDepth`），
  内层结束不会提前提交外层快照（如改序号样式时内部的按阅读顺序重排）。
  撤销 / 重做后清掉已不在文档里的选中项（`AnnotationCanvas.SyncAfterHistory`），
  不留过期虚线框；顶部按钮的可用状态跟随 `CanUndo` / `CanRedo`，**窗口打开时即同步**
  （之前只在文档变化后才同步，刚进编辑器时按钮是亮的却没有历史，点了没反应），
  不可用时置灰并给出「没有可撤销/重做的操作」提示，且禁用的按钮也保留悬浮提示
  （`ToolTipService.ShowOnDisabled`）。
  「清除全部」是一次普通的编辑会话：一步清空画布上的所有标注（含未完成的箭头草稿），
  可 `Ctrl+Z` 整步撤销回来；画布为空时按钮自动置灰，窄屏下与撤销 / 重做一起收成图标。
- **序号**：形状与填充方式即时生效；打开「改样式后重新计数」后，
  改任一号标的形状或填充会按阅读顺序把序号重排为 1、2、3…

适配规则：

- 图片使用 `Uniform` 方式显示，不拉伸、不裁切。
- 初始缩放自动适应窗口。
- 缩放范围 25%–400%。
- 编辑坐标映射回原始像素，缩放只影响显示。
- 左侧工具栏固定 52–56 DIP。
- 右侧属性面板约 240 DIP；可用宽度小于 1000 DIP 时折叠为浮层。
- 窄屏顶部按钮隐藏文字，只保留图标和工具提示。
- 底部状态栏在小屏下只显示尺寸、缩放和当前工具。
- 编辑器支持全屏模式。
- 文本输入框限制在画布可见区域内。

### 4.5 录制控制条

- 录制区域外圈显示 3 px 强调色边框。
- 边框位于截图区域之外，不进入录制画面。
- 悬浮胶囊显示：录制点、时长、帧率、暂停/继续、停止、取消。
- 暂停时边框变为琥珀色。
- 倒计时为独立覆盖层，不写入录制内容。
- 控制条优先位于选区下方，空间不足时吸附到当前显示器顶部安全区。
- 超宽屏不横向铺满。
- 托盘图标同步显示录制状态。

录制前控制条（参考 QQ 录屏）：

- 胶囊式横条，居中位于选区下方，空间不足时翻到上方。
- 内容：格式单选（MP4 / GIF）、清晰度档位、开始录制、退出录制。
- 清晰度仅对 MP4 生效，GIF 档位禁用，避免出现无效开关。
- 未接入音频采集，因此不放置扬声器 / 麦克风按钮。
- `Esc` 等同于退出录制；未点开始时不会创建任何文件。

录制完成预览窗口（参考 QQ「制作MP4」）：

- 自定义标题栏显示格式名，带最小化与关闭。
- 播放区下方：进度条（可拖拽定位）、播放/暂停、`当前 / 总时长`、循环开关、另存为。
- GIF 与 MP4 共用同一窗口：GIF 逐帧推进并按时间轴定位，MP4 通过 MediaElement 定位。
- 底部操作按钮：打开文件 / 打开文件夹 / 另存为 / 复制 / 完成。

### 4.7 设置项

**没有保存按钮**：所有改动即时生效并写盘（文本类输入 350 ms 防抖），只保留「恢复默认」。

- 外观：深色 / 浅色主题，选中即生效，**新装默认浅色（白色外观）**；**托盘图标配色**三选一——
  自动（按任务栏明暗在浅色 / 深色图标间切换，系统主题变化时即时跟着换）、彩色（品牌强调色）、浅色（固定浅色，适合深色任务栏）；
  另有「最小化到托盘时显示提示」开关，配合提示上的「不再提示」按钮可永久关闭该提示。
- 标注：**文本字体**（系统字体对话框选择，`AppSettings.TextFontFamily`，覆盖层文本工具与编辑器新建文本共用，
  设置页下方有实时字体示例）；标注 / 文本颜色改为**取色模式**——覆盖层颜色按钮点击弹系统取色对话框、
  滚轮保留预设色循环，编辑器色板末尾同样有取色块（自定义色未在预设里时该块描边高亮）。
- 存储位置：截图目录 / 录屏目录，失焦或防抖后立即生效，非法值回落默认目录。
- 截图与录制：包含鼠标指针、完成后自动复制、**截图后自动保存到截图目录**（开启时保存按钮直存目录，关闭时弹另存为对话框）、快捷键注册失败弹窗提醒、
  **开机自动启动**（写 HKCU Run 键并带 `--startup`，启动后静默驻留托盘、只注册热键不弹主窗口；
  程序换过安装位置时设置页会自动把启动项修到当前路径）、**启动时检查更新**（默认开，可关闭）。
- 快捷键模式：独立（截图 / GIF / 录屏各自快捷键）或统一（单一快捷键唤起选区，动作在工具条选择；GIF / 录屏快捷键不再注册）。
- 快捷键录入：点一下**直接按下组合键**即可（`HotkeyGesture.TryGetKeyName` 把虚拟键码反查成规范按键名，
  再拼成 `Ctrl+Shift+G` 这类文本走同一套解析与冲突校验）；组合键按**键帽**展示——每个按键各自一个圆角矩形
  （`Presentation/Controls/HotkeyInput`）；`Backspace` 清除、`Esc` 退出录入、`Tab` 换焦点。
- 快捷键模式联动：切到统一快捷键后，GIF / 录屏两行**整行隐藏**（这两个键不会注册，隐藏掉避免误以为能用），切回独立模式立即恢复。
- 鼠标高亮（演示模式）：开关、颜色（#RRGGBB / #AARRGGBB）、直径 16–200 px、不透明度 10–80%；录制引擎在每帧光标位置绘制色圈，GIF 与 MP4 通用，开启时 GIF 也带上光标。
- 选区工具条：区块里直接渲染与真机同款的单行图标工具条（隐藏项变暗），
  按住拖动即可调整顺序、点按钮切换显示 / 隐藏，改动即时生效；没有单独的勾选列表。
  拖动由预览条自己实现（不用 OLE 拖放）：在面板上捕获鼠标，超过 4 px 进入拖动，
  显示竖直插入指示线并把被拖按钮半透明跟随，抬手按落点算目标序号——落在按钮缝隙、分隔线或行末都能换位。
- 快捷键文本非法或彼此冲突时只提示、不落盘，避免把无法注册的组合写进设置。
- 关于是独立导航页（与「设置」平级，排在设置下方），`--page about` 可直达：
  「检查更新」按钮（手动检查，启动时的自动检查可在设置里关闭）+ 结果状态与「下载新版本」入口、
  应用名与版本号（读取程序集版本，即 `csproj` 的 `Version`）、一句话定位、
  GitHub 仓库地址（可点击用默认浏览器打开）、作者、技术栈与开源协议。

### 4.8 MP4 → GIF 转换与预览

- 预览窗口「转 GIF」按钮（仅 MP4 显示）：`Mp4ToGifConverter` 用 MediaPlayer 拖动取样 + `RenderTargetBitmap` 抓帧，复用 GIF 流式编码器，按设置的 GIF 帧率与最大边长转换。
- 转换在 UI 线程异步进行，期间禁用操作按钮并显示进度；完成后写入最近记录并弹提示。

### 4.9 钉图窗口

- 边框为 1 px 强调色，`Topmost` 常驻；左键拖动移动，右下角可拉伸。
- **标注可继续调整**：钉图接收原图 + 标注文档（构造时克隆），中央是 `AnnotationCanvas`，
  鼠标悬浮到标注上即选中（`HoverSelect`，命中容差 4 px），可直接拖动或拖四角调整大小；
  双击文本弹编辑框，`Delete` 删除选中标注（`Esc` 才关钉图），快捷键走 `PreviewKeyDown`。
  按在空白处仍是拖整个钉图窗口。复制 / 另存为 / 存到目录时用 `AnnotationRenderer.Render` 烘焙，
  无标注时直接用原图（保留 DPI）；另存时只烘焙一次，缩略图复用同一张。
- **右键（或悬停）唤出工具条**：复制 / 另存为 / 存到目录 / 精修 ｜ 缩放百分比 ｜ 更多 ｜ 关闭；
  「精修」把当前钉图送进标注编辑器（复用 `EditorWindow`）：**共享同一 `AnnotationDocument` 实例**
  （`shareDocument: true`，不再二次克隆），编辑结果实时反映到钉图，复制 / 保存取到的就是最新版本；
  钉图临时取消 `Topmost` 避免压住编辑器，编辑器关闭后恢复置顶并退订文档事件；
  右键再次按下收起工具条，`Esc` 先收工具条再关闭钉图。
- **滚轮缩放**：围绕光标缩放 10%–400%，工具条上的百分比可点击复位；缩放只改窗口尺寸，不重采样图像。
- `Alt+滚轮`（或「更多」菜单）切换 55% 半透明，便于对照底层内容。
- 另存为默认弹出路径选择框并定位到截图目录；「存到目录」静默写入并提示路径。
- 「更多」菜单沿用主题化 `ContextMenu`（`ChromeBrush` 底 + 圆角），深浅色一致。

## 5. 序号标签设计

### 5.1 编号规则

- 默认下一个编号 = 当前最大编号 + 1。
- 删除末尾编号后，下一个新号自然复用该数字。
- 撤销和重做时编号状态随文档恢复。
- “重排编号”按从上到下、从左到右的阅读顺序重新编号。
- “重置编号”从 1 重新开始，不影响已有标签。
- 每张新截图独立编号，不跨截图延续。

### 5.2 使用方式

- 选择序号工具或按 `N`。
- 点击画布放置，自动递增。
- 工具保持激活，连续点击即可生成步骤。
- 拖动标签调整位置。
- `Delete` 删除选中标签。
- 支持框选多个标签后统一移动。

### 5.3 样式

- 实心圆底 + 白字，默认样式。
- 描边圆。
- 圆角矩形。
- 强调色、线宽、字号可调。
- 导出时按原始图片像素渲染，保证清晰。
- 标签最小字号 12 px，避免缩略图不可读。

### 5.4 导出与编辑

- 序号标签属于矢量标注，不破坏底图。
- 导出 PNG 时按 1:1 像素合成。
- 复制到剪贴板时包含标签。
- 钉图窗口按「原图 + 标注文档」实时渲染（悬浮可选中调整），复制 / 保存时才合成。
- 标签位置和编号参与撤销栈。

## 6. 分辨率与宽高比适配

### 6.1 坐标体系

| 坐标类型 | 用途 |
|---|---|
| 物理像素 | 截图区域、图片尺寸、GIF/MP4 输出 |
| DIP | WPF 窗口、按钮、工具条、断点判断 |
| 显示器工作区 | 主窗口定位、工具条翻转、HUD 防溢出 |

三种坐标只在边界处转换，禁止在业务层混用。

### 6.2 支持范围

| 类型 | 代表分辨率 | 支持策略 |
|---|---|---|
| 16:9 | 1280×720、1366×768、1536×864、1920×1080、2560×1440、3840×2160 | 完整支持 |
| 16:10 | 1440×900、1680×1050、1920×1200、2560×1600、2880×1800 | 完整支持 |
| 3:2 | Surface 2256×1504 等 | 完整支持 |
| 21:9 | 2560×1080、3440×1440 | 完整支持，内容区限制最大宽度 |
| 32:9 | 5120×1440 | 支持，主界面不铺满整屏 |
| 竖屏 | 1080×1920、1200×1920 | 支持截图与录制，编辑器进入紧凑布局 |
| 多显示器 | 双屏、三屏、横排、竖排、混合 DPI | 跨屏连续截图，P0 |
| 任意选区 | 733×419、1024×333 等 | 原样保留，不吸附到标准比例 |

最低可用环境：

- 推荐工作区：1280×720 DIP 以上。
- 最低完整布局：1024×600 DIP。
- 低于 1024×600 DIP 进入紧凑滚动模式。
- 支持 Windows 文本缩放 100%–200%。
- 使用 DIP 断点，不依赖固定像素宽度。

### 6.3 比例锁定

选区工具条提供：

- 自由
- 原始比例
- 16:9
- 16:10
- 4:3
- 3:2
- 1:1
- 9:16

交互规则：

- 固定比例后，拖动选区始终维持比例。
- 切换比例时，以选区中心为基准调整，并限制在屏幕范围内。
- 按住 `Shift` 临时锁定当前比例。
- 尺寸提示同时显示像素尺寸和比例，例如“1280 × 720 · 16:9”。
- 比例锁定只影响选区，不对图片做二次拉伸。

### 6.4 输出规则

- PNG 尺寸严格等于选区尺寸，支持奇数宽高。
- 不自动补边、裁切或转换为 16:9。
- 剪贴板保持原始像素尺寸。
- 缩略图使用等比缩放和留白，不裁切重要内容。
- 钉图窗口按工作区 80% 上限等比缩放，小图不放大。
- GIF 逻辑画布等于录制区域尺寸，支持任意比例。
- GIF 可选最大边长 1920 或 1280，必须等比缩放。
- MP4 保持原始宽高比，不强制 1920×1080。
- H.264 要求偶数宽高：优先从右侧或底部裁去 1 px，录制前明确提示，不拉伸画面。

### 6.5 DPI 与多显示器

- 进程声明 Per-Monitor V2 DPI 感知。
- 使用 Win32 枚举显示器物理边界和工作区。
- 每台显示器独立创建覆盖层，分别适配 DPI。
- 截图和录制只使用物理像素。
- 混合 DPI 下避免跨屏窗口被系统二次缩放。
- 跨屏拖动主窗口时，按新显示器 DPI 重新布局。
- 显示器热插拔、分辨率变化、缩放变化时，重算窗口与编辑器缩放。
- 录制中发生分辨率或显示器排列变化时，自动停止并完成封装。
- 屏幕录制仍然只支持单显示器选区；跨屏能力用于截图。

### 6.6 跨显示器截图

#### 虚拟桌面模型

- 以所有显示器物理矩形的并集作为虚拟桌面边界。
- 坐标使用有符号整数，允许负坐标，兼容位于主屏左侧或上方的显示器。
- 选区、冻结帧和导出均使用虚拟桌面物理坐标。
- 主屏不假设位于 `(0, 0)`，不假设所有显示器顶部对齐。

#### 冻结帧

- 截图开始时逐显示器捕获，再合成一张虚拟桌面冻结帧。
- 每台显示器显示自己的切片，接缝处不重叠、不缩放。
- 显示器之间的空隙不属于任何屏幕，合成时填充黑色。
- 监视器捕获失败时，该区域填充黑色并在状态栏提示。

#### 多覆盖层协同

- 每台显示器一个无边框覆盖窗口，所有窗口共享同一个选区控制器。
- 开始拖动时记录全局物理坐标，并捕获鼠标。
- 拖动过程中通过全局光标位置更新选区，保证指针跨屏后继续有效。
- 所有覆盖窗口实时重绘同一选区，跨越接缝时边框连续。
- 选区确认或取消时，统一关闭全部覆盖窗口。
- 工具条和尺寸提示跟随活动角所在显示器。
- 覆盖窗口使用原生窗口坐标定位，避免 WPF 虚拟坐标与混合 DPI 冲突。

#### 跨屏选区规则

- 选区可跨越水平或垂直排列的显示器。
- 选区限制在虚拟桌面边界内。
- 比例锁定在跨屏选区中同样生效。
- 选区跨越显示器间空隙时，HUD 显示“包含未覆盖区域”，导出以黑色填充。
- 超大选区导出前显示像素尺寸和内存估算。
- 跨屏截图输出为一张 PNG，不拆分文件。

#### 全屏模式

- “当前显示器全屏”捕获鼠标所在显示器。
- “所有显示器全屏”捕获虚拟桌面并集，包含显示器之间的空隙。
- 所有显示器截图同样进入编辑器，可标注和编号。

#### 性能与限制

- 双屏 1080p 冻结目标小于 250 ms。
- 三屏 4K 冻结目标小于 600 ms。
- 跨屏截图内存目标小于 600 MB。
- 受保护内容、HDR 内容和显示器间空隙按已知限制处理。
- 跨屏录制列为 P1；首版录屏仍限制在单显示器内。

### 7.4 领域层几何与编辑规则

领域层只做纯计算（不依赖 WPF），渲染层按它的结果绘制，规则也只有这一份：

- **正心型**：`BadgeShapes.Outline(BadgeShape.Heart, radius)` 用两个等半径圆瓣 + 底部尖点，
  以「尖点 → 圆瓣」的切线连接、顶部取两圆交点作凹口，最后按宽度归一化并垂直居中；
  输出约 53 个顶点，宽高比 ≈ 1、尖点唯一、左右严格对称，浅凹口 + 饱满圆瓣与 ♥ 字形一致。
- **箭头端头**：`ArrowGeometry` 统一端头长度 `clamp(4.2 × 线宽, 8, 44)`（且不超过线段长度）、
  底边半宽 `0.55 × 长度`；`HeadTriangle(from, tip, width)` 返回尖点与两个底角（关于线段轴对称），
  `Ends(ArrowHead)` 给出首 / 尾是否需要端头。渲染层只把三点连成三角形，不再各算一套。
- **多段箭头模型**：`ShapeAnnotation` 保留任意顶点（`Points`），
  `SegmentCount` / `IsMultiSegment` / `StartPoint` / `EndPoint` / `HeadSegment(atEnd)`
  提供段数与端头朝向（首端取第一段、末端取最后一段），折线本身一次描边画完。
- **改样式后重新计数**：`AnnotationEditing.ApplyBadgeStyle(document, badges, apply, renumberOnStyleChange)`
  在一次编辑会话内完成「改样式 +（开关打开时）按阅读顺序重排为 1..n」，
  撤销一次即可回到改样式之前；样式没有实际变化时不写历史；
  编辑器右侧面板与单测共用这唯一入口。

### 7.5 线程模型

- UI 线程：窗口、鼠标交互、状态展示。
- 捕获线程：按帧率抓取桌面。
- GIF 编码线程：量化与 LZW，边编码边写盘。
- MP4 编码线程：颜色转换与写入 SinkWriter。
- 有界帧队列：队列满时丢弃最旧帧并记录丢帧数。
- 取消令牌贯穿捕获、编码和文件写入。
- 异常汇总到录制会话，由 UI 转换为可理解提示。
- UI 线程不执行截图、编码或磁盘写入。

### 7.6 截图管线

1. 枚举所有显示器，得到有符号物理矩形和虚拟桌面并集。
2. 逐显示器 GDI 捕获，合成虚拟桌面冻结帧，空隙填充黑色。
3. 为每台显示器创建覆盖窗口，并绑定同一选区控制器。
4. 在任意显示器按下鼠标，记录全局物理起点。
5. 拖动时读取全局光标位置并更新跨屏选区。
6. 所有覆盖窗口同步绘制选区与遮罩。
7. 确认后按虚拟桌面坐标裁剪冻结帧。
8. 打开编辑器，按原始像素渲染导出。

### 7.7 GIF 管线

- 捕获帧为 BGRA。
- 每帧使用中位切分或八叉树量化到最多 256 色。
- 每帧写入局部调色板。
- 使用 GIF LZW 压缩。
- 默认关闭抖动，优先保持文字和界面边缘清晰。
- 提供高质量抖动选项。
- 写入 Netscape 循环块，默认无限循环。
- 连续相同帧合并并累计延迟。
- 使用临时文件增量写入，完成原子重命名，取消时删除。
- 帧延迟以 10 ms 为单位，界面显示近似帧率，不宣称精确 12 FPS 或 15 FPS。
- 默认最大 120 秒或 2400 帧，可配置。

### 7.8 MP4 管线

- Media Foundation SinkWriter。
- H.264 / MP4，NV12，宽高修正为偶数。
- 优先硬件编码器，失败时回退软件编码。
- 时间戳基于有效录制时间，暂停不推进时间轴。
- 默认码率：1080p 8–10 Mbps，1440p 14–16 Mbps。
- 探测系统 H.264 编码器；Windows N 版缺少 Media Feature Pack 时给出明确提示。
- 写入临时文件，成功封装后原子重命名，失败清理。
- 显示器配置变化时自动停止并封装。

### 7.9 为什么 v1 使用 GDI

- 实现稳定，不依赖 D3D11 和 WinRT 投影。
- 对区域截图和 1080p/1440p 录屏足够。
- 与物理像素选区容易对齐。
- 后续可将捕获层替换为 Windows.Graphics.Capture + DXGI，编码层无需重写。

已知限制：

- 受保护内容可能黑屏。
- HDR 内容可能颜色失真。
- 4K 60 FPS 不是 v1 重点场景。
- 显示器之间的物理空隙无法捕获，跨屏图片中显示为黑色。

| GIF 文件过大 | 分享困难 | 限时长、连续帧去重、可选降采样、显示预计体积 |
| 混合 DPI 多屏坐标错误 | 选区偏移 | 物理像素坐标 + 每屏独立覆盖层 + 多 DPI 真机测试 |
| 跨屏拖动丢失鼠标捕获 | 选区停在屏幕边缘 | 全局光标跟踪 + 原生鼠标捕获 + 超时保护 |
| 跨屏工具条 DPI 错位 | 按钮偏离或模糊 | 按活动显示器 DPI 原生定位 |
| 跨屏大图内存过高 | 卡顿或 OOM | 逐屏捕获、限制三屏 4K、导出前内存估算 |
| 显示器间存在空隙 | 输出出现黑块 | HUD 提示“包含未覆盖区域”，允许取消 |
| 显示器排列在截图时变化 | 坐标失效 | 监听显示变化，立即取消本次选区 |
| 录制边框被录入 | 画面污染 | 边框放在选区外侧，控制条避开录制区域 |
| 热键被占用 | 无法唤起 | 注册失败检测、冲突提示、可重设 |
| 受保护内容黑屏 | 截图不可用 | 明确提示，不绕过系统保护 |
| 剪贴板兼容性 | 无法粘贴 | 同时提供 PNG 与 DIB 格式 |
| 录制崩溃留下大文件 | 占满磁盘 | 临时文件 + 启动清理 + 磁盘空间预警 |
| 分辨率变化破坏录制 | 视频损坏 | 自动停止并完成封装 |
